## Resumo do Projeto


Este projeto propõe o desenvolvimento do SIAA, um Sistema Integrado de Acompanhamento Acadêmico para
a rede estadual do Piauí. A plataforma web visa fortalecer a comunicação entre escola e família, permitindo
que professores publiquem atividades em um calendário interativo e que pais acompanhem o engajamento
dos filhos. O sistema também inclui uma ferramenta para o aluno criar seu cronograma de estudos. O
desenvolvimento usará React para o frontend, Python (Django) para o backend e PostgreSQL como banco de
dados, envolvendo 4 bolsistas Seduc Tec em um ciclo de pesquisa e desenvolvimento que fomenta a inovação e
a aplicação de conhecimento técnico em um problema real da comunidade escolar.
